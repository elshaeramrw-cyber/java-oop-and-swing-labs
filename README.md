# Java OOP & Swing GUI Applications

A collection of Java desktop GUI applications and object-oriented programming exercises covering event handling, custom 2D drawing, encapsulation, and polymorphism.

## 📂 Repository Structure

| File | Category | Description |
| :--- | :--- | :--- |
| `gui/StudentInfoForm.java` | **Swing GUI** | Interactive form layout and user input handling using Java Swing components. |
| `gui/StudentRegistrationGraphics.java` | **Swing & `Graphics2D`** | Combines registration form controls with custom 2D graphics rendering. |
| `gui/CounterMouseApp.java` | **Event-Driven GUI** | Tracks counter state and mouse/action events in a Swing window. |
| `oop/PasswordStrengthAnalyzer.java` | **OOP Logic** | Evaluates password criteria and strength rules using structured classes. |
| `oop/StudentGradeManager.java` | **OOP & Data Handling** | Manages student records and grade calculations with object-oriented methods. |
| `oop/ShapePolymorphismDemo.java` | **Inheritance & Polymorphism** | Demonstrates polymorphic behavior across geometric shape classes. |

## 🛠️ Tech Stack
* **Language & Framework:** Java, Java Swing, `Graphics2D`
